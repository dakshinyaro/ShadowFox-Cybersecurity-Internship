# ShadowFox Cybersecurity Internship

## Intermediate Task 1: VeraCrypt Data Encryption & Recovery

## 📌 Task Overview

This task focuses on understanding and working with **VeraCrypt**, an open-source disk encryption software used to create encrypted containers and protect sensitive information.

The objective of this task is to analyze an encrypted file/container, understand the encryption workflow, and recover the protected data using appropriate techniques.

---

## 🎯 Objective

* Understand the fundamentals of disk encryption.
* Explore VeraCrypt encryption and decryption mechanisms.
* Identify encrypted data files.
* Perform secure mounting and recovery of encrypted information.
* Document the complete analysis process with screenshots and findings.
